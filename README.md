# Huellitas Vet - Diplomado Desarrollo web

Sitio web responsive de una clínica veterinaria ficticia.

## Descripción

Huellitas Vet es una clínica veterinaria ficticia ubicada en Bogotá, Colombia, especializada en la atención de perros y gatos.

El sitio web presenta información sobre la clínica, sus servicios veterinarios, horarios de atención y un formulario demostrativo para el registro de mascotas y propietarios.

## Funcionalidades

- Barra de navegación responsive.
- Carrusel de tres imágenes.
- Presentación de la clínica veterinaria.
- Visualización de servicios veterinarios.
- Tabla de horarios de atención.
- Formulario demostrativo de registro de mascotas.
- Adaptación a celulares, tablets y computadores.
- Navegación entre las páginas del sitio.

## Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Visual Studio Code
- Git y GitHub

## Cómo visualizar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir index.html en un navegador web.
4. Navegar entre las páginas Inicio y, Servicios y contacto.

También se puede la extensión Live Server de Visual Studio Code.

Se requiere conexión a Internet para cargar Bootstrap mediante CDN.

## Nota

Este sitio web corresponde a un proyecto académico ficticio. Los servicios y datos de contacto son ilustrativos.

El formulario de registro es demostrativo y todavía no almacena información.
